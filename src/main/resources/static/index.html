Practical Exam & Viva Quick Reference

Key academic definitions and architecture explanations

1. Strict MVC Layering Flow:

Browser UI (Fetch API) → Controller (@RestController) → Service (@Service) → DAO (@Repository) → MySQL Database (JdbcTemplate).

2. Spring JDBC (JdbcTemplate) vs Raw JDBC:

JdbcTemplate: Automates connection management, exception translation (SQLException → DataAccessException), statement execution, and result mapping (RowMapper).

Raw JDBC: Requires explicit driver loading (Class.forName), manual connection handling (DriverManager.getConnection), parameter binding, and closing resources.

3. Dependency Injection: Constructor vs Field:

Constructor Injection (Best Practice): Guarantees immutability (final fields) and simplifies unit testing without reflection.

Field Injection (@Autowired): Demonstrated on DataSource in StudentDao.java for syllabus Viva requirements.

4. Spring Bean Scopes & Lifecycle:

Singleton: One shared instance per Spring container (Default).

Prototype: New instance created on each request (configured in AppConfig.java).

Lifecycle Callbacks: @PostConstruct (runs after dependency injection) and @PreDestroy (runs before container destruction) in StudentService.java.

5. Aspect-Oriented Programming (Spring AOP):

Implemented in LoggingAspect.java using @Aspect, @Pointcut, @Before, and @After advice to log controller and service execution without polluting business logic.
